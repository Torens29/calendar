# calendar

**Веб-календарь на чистом JavaScript**  
Интерактивный календарь с возможностью просмотра дат и событий, реализованный без использования фреймворков.

## О проекте
Классический веб-календарь, написанный на нативном JavaScript.  
На основе структуры и коммитов можно предположить следующий функционал:
- Отображение текущего месяца с сеткой дней.
- Навигация по месяцам (вперёд/назад).
- Визуальное выделение текущего дня и праздничных.
- Добавление заметок или отметок.
- Адаптивная вёрстка.

## Технологии
- **JavaScript (ES6+)** — генерация сетки календаря, логика переключения месяцев.
- **CSS3** — стилизация таблицы дней, hover-эффекты.
- **HTML5** — базовая структура страницы.
